# mobile-app-prod

Trip is a ride-share app built with Expo and React Native. It uses FastAPI for local development and includes an AWS serverless backend.

## Documentation

- [Getting started](documentation/GETTING_STARTED.md) covers local setup, credentials, AWS deployment, and smoke checks.
- [Architecture](documentation/ARCHITECTURE.md) describes the app, backends, data stores, and ride flow.
- [Change history](documentation/CHANGELOG.md) summarizes project changes by date and records the relevant Git revisions.
- [Bug log](documentation/BUGS.md) tracks open issues and previously recorded fixes.
- [AWS deployment](aws-deployment/README.md) covers the CloudFormation stacks and Lambda operations.
