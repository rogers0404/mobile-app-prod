TECHNICAL ARCHITECTURE
======================

Frontend Component Hierarchy:
┌─ SelectTypeScreen (select-type.tsx)
│  ├─ Main Page
│  │  ├─ Rider Card (clickable)
│  │  └─ Driver Card (clickable)
│  └─ Modal
│     ├─ Header (close button, title)
│     ├─ Mode Buttons (Select Existing / Create New)
│     ├─ Select Mode
│     │  └─ FlatList of Users
│     │     └─ User Card (avatar, name, id)
│     └─ Create Mode
│        └─ Form
│           ├─ Name Input
│           ├─ Info Box
│           └─ Create Button

State Flow:
  User clicks role
    ↓
  setUserTypeModal(type)
  setModalMode('select')
  fetchExistingUsers(type)
    ↓
  Users loaded or error shown
    ↓
  User clicks existing user OR clicks "Create New" tab
    ↓
  If selecting: handleSelectExistingUser(user)
  If creating: handleCreateNewUser()
    ↓
  Save to AsyncStorage
  Navigate to /rider or /driver

Backend Flow:
  GET /api/users?type=rider
    ↓
  Query MongoDB: db.users.find({user_type: "rider"})
    ↓
  Return array of users (up to 100)
    ↓
  Frontend populates existingUsers state
    ↓
  User list displays
