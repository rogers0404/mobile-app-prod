1. CLOUDFORMATION TEMPLATE REVIEW & FIXES (cloudformation-template.yaml)
--------------------------------------------------------------------------------
File: /aws-deployment/cloudformation-template.yaml

BUGS FIXED:
- PolicyText -> PolicyDocument on DocumentsBucketPolicy (S3) and AlertsTopicPolicy (SNS)
- ThrottleSettings -> DefaultRouteSettings with ThrottlingBurstLimit/ThrottlingRateLimit (API Gateway Stage)
- AttributesRequiringVerificationBeforeUpdate -> AttributesRequireVerificationBeforeUpdate (Cognito typo)

- Added GoogleMapsSecret to SecretsManagerAccess IAM policy (was missing)

SECURITY FIXES:
- Added DenyNonSSLRequests statement to S3 bucket policy (enforce HTTPS only)
- Added ObjectLockEnabled: true to S3 DocumentsBucket
- Added S3 cross-region replication + S3ReplicationRole IAM role
- Added KmsMasterKeyId: alias/aws/sns to SNS AlertsTopic
- Added DatapointsToAlarm: 1 to CloudWatch alarm
- Added PointInTimeRecoverySpecification to RidesTable and PaymentsTable
- Added TimeToLiveSpecification (TTL) to all 3 DynamoDB tables (users, rides, payments)

4. LAMBDA FUNCTIONS CLOUDFORMATION (lambda-functions.yaml)
--------------------------------------------------------------------------------
File: /aws-deployment/lambda-functions.yaml
Created from analysis of: server.py, 01-ARCHITECTURE.md, LAMBDA_TEMPLATE.md

7 LAMBDA FUNCTIONS CREATED:
  1. trip-users-production
     Handler: users.lambda_handler
     Routes: POST /api/users/create, GET/PUT/DELETE /api/users/{user_id}

  2. trip-driver-production
     Handler: driver.lambda_handler
     Routes: POST /api/driver/documents, /location, /status
             GET  /api/driver/{id}/documents, /status, /pending-rides,
                  /active-ride, /earnings

  3. trip-rides-production
     Handler: rides.lambda_handler
     Routes: GET  /api/rider/nearby-drivers
             POST /api/rides/request, /accept, /update-status, /rate
             GET  /api/rides/{id}/active, /history, /details/{id}

  4. trip-payments-production
     Handler: payments.lambda_handler
     Routes: POST /api/payment/create-order, /capture-order

  5. trip-places-production
     Handler: places.lambda_handler
     Routes: GET /api/places/search, /places/details, /directions

  6. trip-websocket-production
     Handler: websocket.lambda_handler
     Routes: WS /api/ws/{user_id} (connect, disconnect, location broadcast)

  7. trip-notifications-production
     Handler: notifications.lambda_handler
     Trigger: SQS NotificationQueue consumer

ALL FUNCTIONS:
  - Runtime: python3.11
  - Memory: 512 MB
  - Timeout: 30s
  - X-Ray tracing: Active
  - CloudWatch log groups: 30 day retention

3 SQS QUEUES + 3 DEAD LETTER QUEUES:
  - trip-ride-requests-production (DLQ: trip-ride-requests-dlq-production)
  - trip-payment-processing-production (DLQ: trip-payment-processing-dlq-production)

IAM ROLE: trip-lambda-role-production

CLOUDWATCH ALARMS:
