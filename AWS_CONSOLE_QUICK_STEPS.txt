📋 PREREQUISITES (Get these ready FIRST)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

✅ Have these ready:
   □ AWS Account login credentials
   □ PayPal Sandbox Client ID
   □ PayPal Sandbox Secret Key
   □ Google Maps API Key
   □ Optional: Stripe API Keys

📂 Files you'll need:
   □ CLOUDFORMATION.md (contains the template)
   □ AWS_CONSOLE_CLOUDFORMATION_GUIDE.md (detailed instructions)
   □ parameters-example.json (parameter template)

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

⚡ QUICK STEPS (5 minutes)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1️⃣  OPEN AWS CONSOLE
    ├─ Go to: https://console.aws.amazon.com
    ├─ Sign in with your AWS account
    └─ Make sure region is: us-east-1 (top right)

2️⃣  NAVIGATE TO CLOUDFORMATION
    ├─ Click search bar at top
    ├─ Type: CloudFormation
    ├─ Click "CloudFormation" in results
    └─ You'll see "Create stack" button

3️⃣  CLICK "CREATE STACK"
    ├─ Look for "Create stack" button (top right, red/orange)
    ├─ Click the dropdown arrow next to it
    └─ Select: "With new resources (standard)"

4️⃣  SPECIFY TEMPLATE
    ├─ You'll see "Create stack" page
    ├─ Under "Prerequisite - Prepare template"
    ├─ Confirm: "Template is ready" is selected ✓
    ├─ Under "Specify template"
    ├─ Choose: "As text"
    ├─ Paste CloudFormation template from CLOUDFORMATION.md
    │  (Copy from "AWSTemplateFormatVersion:" to the end)
    └─ Click "Next"

5️⃣  ENTER STACK DETAILS
    ├─ Stack name: trip-ride-share
    ├─ Environment: production (from dropdown)
    ├─ PayPalClientId: YOUR_PAYPAL_CLIENT_ID
    ├─ PayPalSecret: YOUR_PAYPAL_SECRET
    ├─ GoogleMapsKey: YOUR_GOOGLE_MAPS_KEY
    └─ Click "Next"

6️⃣  CONFIGURE STACK OPTIONS
    ├─ Optional: Add tags for organization
    │  (Key: Environment, Value: Production)
    ├─ Optional: Enable "Termination protection"
    └─ Click "Next"

7️⃣  REVIEW & CREATE
    ├─ Review all your entries
    ├─ IMPORTANT: Check the box:
    │  "I acknowledge that AWS CloudFormation might
    │   create IAM resources"
    └─ Click "Create stack"

8️⃣  WAIT FOR COMPLETION
    ├─ You'll see: "Stack creation initiated" (green)
    ├─ Status shows: CREATE_IN_PROGRESS (yellow)
    ├─ Wait 5-15 minutes for completion
    ├─ Watch the Events tab for progress
    └─ Final status: CREATE_COMPLETE (green) ✅

9️⃣  GET YOUR API ENDPOINT
    ├─ Click "Outputs" tab
    ├─ You'll see API Gateway URL
    ├─ COPY THIS: https://xxxxxxx.execute-api.us-east-1.amazonaws.com/prod
    └─ Use this in your frontend!

🚨 TROUBLESHOOTING
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

❌ "CREATE_FAILED" Status
   ├─ Check the Events tab for error message
   ├─ Common: Invalid PayPal/Google API credentials
   ├─ Solution: Delete stack and try again with correct credentials
   └─ See: AWS_CONSOLE_CLOUDFORMATION_GUIDE.md for details

❌ Can't find "Create stack" button
   ├─ Make sure you're in CloudFormation service
   ├─ Refresh page (Ctrl+R or Cmd+R)
   └─ Check you're signed in to AWS

❌ "I acknowledge that AWS CloudFormation..." checkbox missing
   ├─ Scroll down on the Review page
   ├─ It's at the bottom
   └─ Must check before clicking Create

❌ Getting "AccessDenied" errors
   ├─ Your AWS user might not have permissions
   ├─ Use an account with AdministratorAccess
   └─ Or ask your AWS administrator to enable CloudFormation
